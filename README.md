# Moja Lodówka

W życiu studenckim (i nie tylko) ważne jest to, aby zadbać o zdrową i bogatą dietę. Często jednak nie mamy pomysłu na danie, nie chce nam się myśleć ani robić zakupów. Z pomocą przychodzi nasza aplikacja, w której użytkownik będzie mógł:
zapisywać ilości i terminy ważności poszczególnych produktów w lodówce: poprzez skanowanie kodów kreskowych kupowanych produktów lub ich ręczne wprowadzanie
dostawać powiadomienia o zbliżającym się terminie ważnosci produktów
przeglądać dania z różnorodnych stron i blogów kulinarnych, wymaganych do ich przyrządzenia składników oraz ich wartości odżywcze; po sam przepis będzie odsyłany do właściwej strony internetowej, z której wzięto opis (wymagane przez prawa autorskie, później możliwe dodanie większej ilości źrodeł danych np. otwarte API)
filtrować dania według możliwości ich przygotowania ze składników obecnie znajdujących się w lodówce, ulubionych, diety, lub dodawać własne
dostosowywać ilość porcji dania, które chce przygotować (proporcjonalnie większa lub mniejsza ilość składników)
automatycznie sporządzać listę zakupów na podstawie brakujących składników potrzebnych do przygotowania danego dania

Dodatkowo planowana jest integracja z aplikacją Fitatu: automatyczne dodawanie zjedzonej potrawy do planera dnia.

Naszą trudnością w tym zadaniu i wiedzą, którą w ramach tego projektu musimy zdobyć jest web scraping, wszelkie wyciąganie danych ze stron internetowych i manipulowanie nimi oraz wysyłanie powiadomień w konkretnych godzinach i odstępach czasowych.
